Use of generative AI

Generative-AI tools were used as assistance during this master's degree. The author reviewed the suggestions, made the final decisions and remains responsible for the submitted work. This page records the main uses and examples of the instructions and prompts.

On this page Literature search and source checking Other uses of generative AI Representative prompts Tools used

Literature search and source checking

A retrieval-augmented generation (RAG) system was developed to assist with searching a local repository of downloaded publications. AI tools also assisted with finding relevant literature and locating passages for consideration.

The author read the recommended publications and checked the relevant passages and claims before inclusion. The author formulated the arguments from the source publications and approved the final wording.

Other uses of generative AI

AI tools provided assistance with:

  • Grammar and spelling checks.
  • Code development, debugging and review.
  • Reviews of simulation setups.
  • Figure preparation and the supplementary website.

Reusable instructions guided grammar and spelling suggestions while requiring preservation of the meaning and technical content. The author reviewed and approved proposed changes before inclusion.

No confidential data were provided to the AI systems.

Representative prompts

Code-correctness review 
 Review the code file(s) [user input to the relevant directories] for logical and numerical correctness. Check array dimensions, tensor shapes, indexing, transformations,
            data leakage, random-state handling and consistency between the implementation and the stated analysis: [user describes the implementation and intended analysis]
            Report each confirmed problem with the evidence used to identify it. If any errors are found list them with suggested corrections.
Simulation-setup review 
Review the completed simulation setup [user input to the relevant directories]. Check that the assumptions, parameter values, random seeds, comparison baselines,
            repetitions and evaluation measures answer the intended question: [user input of the intended question]. Identify confounding choices or cases in which the simulated evidence would
            not support the stated interpretation: [user input the interpretation]. If any errors are found list them with suggested corrections.
Figure development 
Create or revise the figure using the following information and specifications:

[User-supplied figure requirements, design choices and source data]

Preserve every numerical value and label and produce a transparent figure. Save the figure-generation code and outputs in the relevant project directory:

[Path to the relevant project directory]
Software debugging 
The code produces the following error or unexpected behaviour:

[User description of the error, observed behaviour and suspected causes]

Diagnose the reported behaviour and identify potential causes. List the potential errors and suggested code changes.
