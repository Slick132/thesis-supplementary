Strided convolution

A strided convolution moves the kernel more than one position at a time. This example uses 17 input positions, a kernel width of seven and stride two, without padding. Six complete windows fit within the input. Consecutive windows overlap by five positions.

Dilated convolution

The animation makes a separate left-to-right pass for each dilation rate. Seven weights are used in every pass. No padding is used in this toy example, so increasing dilation reduces the output length.

A dilated convolution spaces the kernel weights apart according to the dilation rate. Increasing dilation widens the kernel span without increasing the number of weights. With stride one, same padding preserves the sequence length. Without padding, the output becomes shorter because only kernel positions fully contained within the input are evaluated.

weights=k=7 kernel span=d (k−1) +1

Dilated convolution with same padding

This smaller example illustrates one dilated layer. Seven weights at dilation two span 13 positions. With stride one, six zero-padding positions at each end preserve the length: 12 input positions produce 12 output positions.

Growth of the receptive field

The receptive field is the span of input positions that can influence one output position. Stacking convolutional layers increases this span when the filters combine multiple positions. The amount of growth depends on the filter width, dilation and the strides of preceding layers.

The animation compares three example stacks with a filter width of three. Standard convolutions expand the span gradually. Strided convolutions increase the spacing between output positions, allowing later layers to cover a wider input span. Dilated convolutions read spaced positions without requiring a larger stride.

The bars show the theoretical input span for one convolutional output position, assuming a sufficiently long input. Equal spans do not imply identical computations or output resolution. Pooling and fully connected layers can combine information across additional positions.

Adaptive average pooling

Adaptive average pooling reduces a sequence to a specified number of output positions by averaging the values within each pooling window. The window boundaries depend on the input and requested output lengths. Pooling is applied independently to each feature channel, so the number of channels remains unchanged. Global average pooling is the special case with one output position per channel, calculated by averaging over the entire sequence.

Transposed convolution

The transposed convolution is the decoder counterpart of the strided layer. Each input position multiplies the entire kernel and scatters its contributions across several output positions, and where those contributions overlap they are added. The operation increases the temporal length when the stride exceeds one, learns its own weights, and is the transpose of the corresponding linear operation rather than an inverse convolution, so it cannot guarantee recovery of information lost during downsampling.

Lout= (Lin−1)s −2p +d(k−1) +pout +1

The 1 x 1 convolution

A 1 x 1 convolution looks at all feature channels at one temporal position and learns a new weighted combination of those channels. The operator mixes feature channels and can change the number of feature maps without combining neighbouring positions. With stride one, the sequence length and receptive-field span remain unchanged. The number of filters determines the number of output channels, allowing the layer to reduce, preserve or increase the channel count.

yq,t =bq+ ∑c=1Cin wq,c xc,t

The animation uses four input and three output channels so the calculation remains visible.

Convolution over a multichannel series

A filter slides along time and reads every input variable at each position, so one output value combines information across input channels and neighbouring positions. A layer holds several filters, and each produces its own feature map. The feature maps are learned combinations of the inputs rather than direct copies of individual input variables.

Each filter holds a separate kernel for every input variable, so the weights of this layer form a block of shape 3 x 2 x 3, being the number of output feature maps, the number of input variables and the kernel width. The animation uses a width-three kernel with stride one and a single zero-padding cell at each end, which is why the 12 positions survive the layer. Without that padding a width-three kernel would leave 12 - 3 + 1 = 10 positions.

Two variables over twelve positions and three filters. The tilde marks the zero-padded input, and the highlighted window is the current kernel position and the value beneath is the output after the activation.

Nonlinear activation

A nonlinear activation transforms the output of a layer. Without nonlinear activations, a stack of affine layers is equivalent to a single affine mapping. This example shows the Gaussian error linear unit (GELU), which scales each input according to its value.

hq,t = GELU ( aq,t )

Flattening and the fully connected bridge

Flattening rearranges a feature tensor into a vector without changing its values. A fully connected bridge then combines these values using learned weights. A hidden layer with a nonlinear activation is followed here by a linear mapping to a smaller embedding.

h=GELU ( W1v+b1 ) z=W2h +b2

The shape chain and small network are illustrative examples of flattening followed by learned feature combinations.

Decoder bridge and reshape

A decoder bridge maps an embedding to a longer vector using learned layers. Reshaping arranges the vector into channels and sequence positions for subsequent processing. The bridge is learned separately from the encoder; reshaping itself only changes the arrangement of values.

Flattening and reshaping only rearrange values. The order is fixed, so the two operations are exact inverses of one another.

Linear interpolation

Linear interpolation estimates intermediate values between neighbouring positions. It changes the sequence length without learned weights and is applied independently to each channel. Increasing the number of positions does not recover information discarded by an earlier reduction.
