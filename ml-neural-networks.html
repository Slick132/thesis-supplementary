Artificial neurons and layered networks

A neuron calculates a weighted sum of its inputs, adds a bias and applies an activation function. Arranging these units in layers creates a nonlinear mapping from an input vector to an output vector.

h(ℓ)=φ(ℓ)(W(ℓ)h(ℓ−1)+b(ℓ))

The same operation is repeated through the hidden layers. Early layers transform the original variables, while later layers combine the transformed values into task-specific features.

Training through loss minimisation

A loss function measures disagreement between the model output and its target. Backpropagation calculates the gradient of the loss with respect to each parameter. A gradient-based optimiser then updates the weights and biases over successive mini-batches.

Convolutional operators

A convolution applies one learned kernel to successive local windows. Reusing the kernel allows the same temporal pattern to be detected at different positions. A strided convolution reduces the sequence length, while a dilated convolution spreads the kernel taps apart and widens the receptive field without adding kernel parameters.

StrideMoves the kernel by more than one position and downsamples the sequence.
DilationAdds gaps between kernel taps and expands the temporal view.
TransposeIncreases sequence length in the decoder but is not an inverse convolution.

The receptive field of deeper layers grows because each output combines the receptive fields of the preceding layer. The animated architecture search shows these operations layer by layer for the models evaluated in the thesis.

Autoencoders

An autoencoder contains an encoder that maps an observation to a lower-dimensional embedding and a decoder that reconstructs the observation from the embedding. Training minimises reconstruction error, so the bottleneck must retain information required to reproduce the inputs.

z=genc(x),x^=gdec(z)

The final environmental model used a convolutional encoder and decoder because every observation contained six aligned daily time series. The bottleneck reduced each complete record to five embedding values used for subsequent interpretation and clustering.
