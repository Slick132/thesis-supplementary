Autoencoders and embedding geometry

This page explains how an autoencoder represents an observation as a code, how the decoder shapes distances in that code space, and why Euclidean distance between codes is not always a measure of similarity between the reconstructed observations.

Autoencoders

An autoencoder contains an encoder that maps an observation to a lower-dimensional embedding and a decoder that reconstructs the observation from the embedding. Training minimises reconstruction error, so the bottleneck must retain information required to reproduce the inputs.

z=genc(x),x^=gdec(z)

Autoencoder geometry

This section explains how the decoder shapes distances in the learned representation space, including the pullback metric and decoded paths used in the thesis analysis.

Why latent distance needs checking

An encoder f maps an input to a lower-dimensional code and a decoder g that reconstructs the input from the code. A common downstream workflow treats the codes as ordinary feature vectors and applies clustering with Euclidean distance. This workflow assumes that distances between codes reflect differences between the corresponding reconstructed inputs.

Reconstruction loss does not directly impose that constraint. Similar inputs are not guaranteed to receive nearby codes, and nearby codes are not guaranteed to decode to similar outputs. The decoder can stretch one part of the code space and compress another.

Geometric role of the autoencoder

The decoder learns a reconstructed surface, denoted Mrec, and that surface need not coincide with the true data manifold. The encoder maps an input to a code in Z and the decoder maps that code back into the input space. The reconstructed surface is a surface inside input space. Reconstruction loss drives that surface towards the true data manifold, so the surface approximates the manifold rather than reproducing it.

f:Rd →Z g:Z→ Mrec ⊂Rd

Latent codes act as coordinates for the reconstructed surface. Equal steps in those coordinates does not necaserily produce equal changes after decoding, even when reconstruction is accurate.

The decoder is the mapping that stretches. A stretch between two codes turns a small code-space distance into a large distance in the reconstructed input. Latent distance therefore measures position in the code space rather than similarity of the reconstructed inputs. The codes are nevertheless often used directly, with Euclidean distance taken as a measure of similarity and the decoder-induced distortion left unchecked. Empirical evidence does seem to support this, since there generally seems to be little curvature [3]. Curvature and coordinate distortion are nevertheless different properties, and clustering under the Riemannian distance agreed better with the true classes than clustering under the Euclidean distance [1]. The next subsection describes how to measure that distortion.

Decoder Jacobian and pullback metric

The decoder Jacobian describes the local response of the reconstructed output to a small change in each latent coordinate. For a decoder from a p-dimensional code space to a d-dimensional input space, the Jacobian at code z is

Jz= ∂g(z) ∂z ∈R d×p

The Jacobian therefore quantifies the local stretching of the decoder. Each column gives the input-space direction produced by a small displacement along one latent axis, and the length of that column is the factor by which the decoder stretches a step along the axis. The pullback metric combines these directions into a local measure of decoder distortion:

Mz= Jz⊤ Jz ∈R p×p

For a small latent displacement, the quadratic form below approximates the corresponding squared change in the decoded input:

Δz⊤ Mz Δz

A large value means that the decoder turns a small latent step into a large reconstructed change. A small value means that the same latent step produces little reconstructed change. Variation in the metric across the code space therefore describes local stretching and compression by the decoder.

Curvature and coordinate distortion

A flat manifold does not guarantee undistorted latent coordinates: the decoder can still stretch one region and compress another. Intrinsic curvature and coordinate distortion are therefore different properties. Whether Euclidean latent distance approximates decoded distance must be checked for the fitted model.

A flat sheet of paper rolled into a spiral illustrates the distinction. The paper is not stretched, so the surface remains flat, yet a straight line drawn through the rolled sheet does not follow the paper. A flat surface can therefore be described by coordinates that distort distances.

The deterministic pullback metric used in the thesis measures decoder sensitivity rather than predictive uncertainty, and it describes a single fitted decoder rather than a distribution over plausible decoders.

Decoded paths

A simple decoder-induced path places equally spaced points on the straight line between two latent codes, decodes every point and sums the Euclidean distances between consecutive decoded outputs. This procedure measures the length of the decoded straight path, not necessarily the shortest path on the reconstructed manifold.

For a continuous latent curve γ, the Riemannian length equals the arc length of the decoded curve:

L[γ]= ∫01 γ˙t⊤ Mγt γ˙t dt

Geodesics and minimal decoded paths

The geodesic is the path with the smallest length under this metric. In distorted latent coordinates the geodesic is not necessarily a straight line, so the shortest decoded route between two codes cannot be assumed to be the linear interpolation used above.

The discrete decoded-arc-length energy and the minimisation procedure below follow Shao et al. [3], who minimised this energy over the interior path points with the endpoints held fixed. Shao et al. stopped the optimisation on the squared gradient norm, whereas the thesis stopped it on the relative change in the energy.

Discrete geodesic procedure

  1. Place T path points on a linear interpolation between the two fixed latent endpoints.
  2. Treat the interior path points as optimisation variables while keeping the endpoints fixed.
  3. Decode every path point using the trained decoder.
  4. Calculate the sum of squared distances between consecutive decoded outputs.
  5. Backpropagate through the decoder and update the interior path points.
  6. Repeat until the relative change in the energy is below the convergence tolerance or the iteration limit is reached.

The discrete decoded-arc-length energy is

E[γ]= ∑i=0 T−2 ‖g(zi+1) −g(zi)‖ 2

Use in the thesis

The 9,364 training embeddings produced more than 43 million unique pairs, so a complete Riemannian distance matrix was not constructed and the full dataset was not reclustered under that metric.

The main diagnostic used nearest-neighbour graph edges. Each straight latent path was divided into ten segments. The 11 decoded outputs were flattened across all six channels and time steps, and the consecutive decoded distances were summed. These path lengths were correlated with Euclidean distances in the standardised embedding.

For 1,200 sampled pairs spanning the Euclidean distance range, the interior path points were also optimised from a linear initialisation. This checked whether the straight-path conclusion remained valid when the decoded path energy was minimised.

Pairwise Riemannian distances can be used directly by methods that accept arbitrary dissimilarities, including hierarchical clustering and graph-based analyses. Standard K-means requires coordinates and cannot accept an arbitrary distance matrix without a separate Riemannian formulation.
